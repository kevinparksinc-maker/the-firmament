SYSTEM ARCHITECTURE
================================================================================

LAYER 1: EPHEMERIS (astronomy-engine)
- Topocentric planetary positions (sidereal)
- House cusps (equal house system)
- All 12 planets + nodes
- Retrograde detection
- Altitude/azimuth for dome rendering

LAYER 2: HOUSE EVALUATION (fullHouseEvaluation.ts)
- All 12 houses evaluated independently
- Lord dignity (exalt/own/peregrine/detriment/fall)
- Territory scoring (own cluster vs opponent cluster)
- House type bonus (angular/succedent/cadent)
- Planets in house (benefic/malefic)
- Aspects to house lord (benefic/malefic conjunctions)

LAYER 3: TERRITORIAL CONTROL (territorialControlEngine.ts)
- Lords in own cluster: +1 to +2 per house
- Lords in opponent cluster: -1 to -3 per house
- Extra penalty for opposition angles (H1↔H7, H10↔H4)
- This layer consistently outperforms raw dignity scoring

LAYER 4: ARABIC LOTS (arabicLotsCalculator.ts)
- 8 core lots with traditional formulas
- Day/Night adjustment for Lot of Fortune
- Placement scoring based on cluster house
- Nemesis reversal: -3 for Ascendant angular, +1 for Descendant angular

LAYER 5: FIXED STARS (fixedStarsCoreList.ts)
- 8 core stars: Regulus, Spica, Aldebaran, Antares, Fomalhaut, Sirius, Arcturus, Algol
- Tight orbs (0.5-1.0°)
- Amplify existing signals rather than create new ones
- Conjunctions to personal planets and lords score highest

LAYER 6: RETROGRADE PLANETS
- -1 point per retrograde in Ascendant cluster
- -0.5 points per retrograde in Descendant cluster
- Mercury retrograde especially critical

LAYER 7: MOON PHASE
- Waxing: +1 for Ascendant (favorable for initiated action)
- Waning: +1 for Descendant (favorable for defensive/reactive)

LAYER 8: COMBUSTION/CAZIMI
- Combust (near Sun): -1 point
- Cazimi (in Sun's heart): +2 points

HOUSE CLUSTERS vs ALL HOUSES
